# Offline Reference Library

This directory holds compact, stable reference material for mentoring. It is intentionally
not a substitute for primary sources, qualified pastoral care, or up-to-date professional
guidance.

- `coaching-principles.md` supplies the reusable decision, reflection, and review method.
- `theological-framework.md` records doctrinal boundaries and stable primary-source
  locators.

Use these notes before browsing. Add a local source note when research is repeated, and
include its title, author/organization, stable URL or edition, access date, the claim it
supports, and a short excerpt or locator. Re-check sources only when the claim is
time-sensitive, contested, or material to the user's decision.
