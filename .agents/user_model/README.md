# User Model

This private, ignored directory is the agent's compact, evidence-linked working model of
the user's life context and growth. It reduces repeated questioning; it must never become
an unsupported psychological profile.

Maintain one file per domain as needed, for example:

- `current-context.md`
- `goals-and-commitments.md`
- `strengths-and-resources.md`
- `patterns-and-growth-edges.md`
- `relationships-and-responsibilities.md`

Use `.agents/templates/user-model.md`. Mark confidence, cite dated record IDs, distinguish
the user's stated view from an agent inference, and replace stale assumptions. Ask before
recording sensitive facts that are not necessary for mentoring.
