# Agent Journal

This private, ignored directory contains concise coaching-process notes, not transcripts.
Create one dated note from `.agents/templates/agent-journal.md` only when it reduces
future repeated discovery: a successful approach, a durable preference, a review due
date, or a supported model update.

Every statement about the user should link to a decision or reflection record and state
its confidence. Remove or correct stale notes when later evidence contradicts them.
